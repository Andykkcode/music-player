# Music Player 🎵

一个用原生 HTML / CSS / JavaScript 写的网页音乐播放器，零框架、零依赖、开箱即用。

## 在线体验

👉 https://andykkcode.github.io/music-player

## 功能

- 本地音乐导入（支持一次选择多首）
- 歌单管理：添加、删除、点击切换、当前播放高亮
- 上一首 / 下一首，播完自动切歌
- 进度条拖动跳转、音量调节
- 三种播放模式：顺序播放 / 单曲循环 / 随机播放
- 复古黑胶唱片机外观：播放时唱片旋转、唱臂落下，标签实时显示当前歌名

## 技术栈

HTML5 Audio API · CSS3 · Vanilla JavaScript

## 本地运行

下载本仓库，双击 `index.html` 即可，无需安装任何环境。

## 使用说明

1. 点击「添加歌曲到歌单」，从本地选择音乐文件（mp3 / wav / ogg 等浏览器支持的格式）
2. 点击歌单里的歌曲即可播放
3. 播放时唱片会旋转，唱臂落下；点击模式按钮可在顺序 / 单曲循环 / 随机之间切换

> 提示：音乐文件只在本机浏览器中读取，不会上传到任何服务器。
